# CivilStock 설계 제안 (초안)

> 유저가 직접 국가를 세우고, 경제·전쟁·외교를 자유롭게 벌이는 오픈 웹앱 게임.
> Google(Firebase) 환경. 2DStock의 아쉬웠던 점을 정면으로 개선한다.

## 0. 2DStock 회고 — 무엇이 아쉬웠나

2DStock 아키텍처를 그대로 요약하면:

- **시장은 클라이언트에서 결정론으로 계산**(고정 기원점) → 모두가 같은 세계를 봄.
- **Supabase는 계정 레이어**(로그인·지갑 저장·랭킹)만 담당.
- 정적 사이트(GitHub Pages) 배포.

여기서 나온 구조적 한계:

1. **유저 간 실질 상호작용이 없다.** 전쟁·외교가 스크립트/스케줄 이벤트지, 상대
   플레이어를 향한 행위가 아니다. 사실상 "공유된 시뮬레이션을 상대로 한 솔로
   플레이 + 랭킹".
2. **클라이언트 권위 → 조작에 취약.** README도 "e스포츠급 검증이 아니라 캐주얼
   조작 억제용"이라고 명시.
3. **기능 스프롤.** 시장·IPO·옵션·공매도·ETF·미니게임 등 100+ 파일. 재미의 축이
   분산됨.
4. **세계가 지속되지 않는다.** 회차/프레스티지 리셋 루프라 "내가 쌓은 것이 세계에
   남는다"는 감각이 약함.

CivilStock은 이 4가지를 뒤집는다: **서버 권위형·지속되는·유저가 만드는 세계.**

## 1. 핵심 방향 전환 3가지

| 축 | 2DStock | CivilStock |
|---|---|---|
| 권위 | 클라이언트 결정론 | **서버 권위**(Cloud Functions) |
| 상호작용 | 없음(솔로+랭킹) | **유저 간 국가 상호작용**이 게임의 본체 |
| 세계 | 회차마다 리셋 | **지속 세계 + 에포크(시즌) 소프트 리셋** |

## 2. 왜 "틱 기반 비동기"인가 (트위치 실시간 아님)

웹앱 게임의 최대 현실: **플레이어가 24시간 접속하지 않는다.** 실시간 RTS로 만들면
접속 안 한 사람이 일방적으로 털린다. 그래서:

- 세계는 **정기 틱**으로 전진한다. 예: 현실 1시간 = 게임 1일, 하루 24틱.
- 모든 국가는 **정책(policy)으로 자동 운영**된다 — 세율, 생산 우선순위, 국방
  태세, 교전 규칙(ROE). 접속하지 않아도 내 국가는 내 정책대로 굴러간다.
- 접속은 "정책을 바꾸고, 외교를 하고, 전쟁을 선포하는" 의사결정의 순간이지,
  "APM으로 손을 놀리는" 순간이 아니다.
- 전투/침공은 즉발이 아니라 **여러 틱에 걸쳐 진행** → 방어자가 대응(동맹 소집,
  방어 정책 전환, 강화 요청)할 시간을 보장. 오프라인이어도 자동 방어 발동 +
  푸시 알림.

이게 웹앱·모바일·비동기 플레이와 서버 비용(Cloud Scheduler 틱) 모두에 맞다.

## 3. 게임 시스템

### 3.1 국가 설립
- 공유 맵(헥스/지역 그리드). 빈 영토에 깃발을 꽂아 건국.
- 초기 자원 1인 지급, 수도 1칸. 신생국은 **보호 기간**(예: 실시간 3일 / 일정
  국력 도달 전까지) 동안 침공 불가.
- 국가는 **멀티 플레이어 가능**(선택): 지도자 + 장관/장군 역할. 길드 = 국가.
  솔로도 1인 국가로 가능.

### 3.2 경제 (여기서 큰 수 모듈이 핵심)
- 자원 → 생산 체인 → 재화 → 시장. 처음엔 2~3종으로 좁게 시작(식량·자재·통화).
- **국고·GDP·통화 발행량은 천문학적 수**가 된다 → `exactAmount`(BigInt 문자열)로
  전부 처리. Firestore엔 문자열로 저장, Function에서 BigInt 연산. float 금지.
- 국가별 **자국 통화** 발행 가능 → 환율/인플레이션. 통화를 찍으면 물가가 오른다
  (하이퍼인플레 리스크 = 전략 선택).
- 유저 간·국가 간 **무역**: 자원 수출입, 관세, 금수(embargo).
- 세금·국채: 국채 발행으로 전쟁 자금 조달 → 이자 부담이라는 반대급부.

### 3.3 외교
- 조약 시스템: 불가침, 동맹, 자유무역, 통행권, 연방/합병.
- **평판(신뢰도)**: 조약 파기·기습 선전포고는 평판을 깎아 향후 동맹 성사율↓.
- 연합(coalition): 패권국에 맞서 다수가 자동/수동 결집 → 스노우볼 억제(3.6 참고).
- 스파이/첩보(후순위): 정보 비대칭이 외교의 재미.

### 3.4 전쟁
- 군대 = **경제 산출을 전환**해 만든 것(병력·장비 = 자원 소모). 즉 전쟁은
  경제를 태우는 행위 → 남발 불가, 전략적 선택.
- 선전포고 → 동원 → 다틱 교전 → 영토 점령/약탈. 전쟁 피로도(war exhaustion)로
  장기전은 국내 경제·안정도에 페널티.
- 점령해도 즉시 편입 아님: 점령지 저항/치안 유지 비용 → "정복만능" 방지.
- 방어 우위 설계: 수성이 공성보다 유리하게 기본 세팅(오프라인 방어 보호).

### 3.5 내정·정치
- 정부 형태(민주정/과두정/전제정 등) 각각 트레이드오프: 생산 보너스 vs 반란
  리스크 vs 정책 변경 속도.
- 안정도/여론: 세금·전쟁·물가가 안정도에 영향. 낮으면 반란·분리독립.
- 멀티 플레이어 국가는 내부 정치(쿠데타, 선거, 권력 분배)가 그 자체로 콘텐츠.

### 3.6 반(反)스노우볼 — 지속 세계 게임의 생사

지속 세계의 최대 적은 **강자독식·신규 절망**. 대응 장치를 처음부터 박는다:

- **규모 역페널티**: 영토·인구가 클수록 유지비·부패·관리 난도 상승(수확체감).
- **신생국 보호 + 캐치업**: 후발 주자에 성장 보너스, 약소국 연합 보너스.
- **연합 자동 형성**: 1위 패권국을 향한 외교 페널티/연합 결성 유인.
- **전쟁 피로·점령 비용**: 무한 정복 억제.
- **에포크(시즌)**: 지속 세계지만 일정 주기(예: 시즌 6~8주)로 **소프트 리셋**.
  세계는 새 지도로 리셋, 개인은 **레거시/명예 포인트**(2DStock 프레스티지의
  세계 스케일 버전)와 칭호·스킨·시작 보너스를 계승. "내 업적은 남고, 판은
  새로 열린다." → 신규·복귀 진입장벽 해소 + 세계 정체 방지 동시 해결.

## 4. 기술 아키텍처 (Google / Firebase)

```
[웹앱 클라이언트]  ──읽기(구독)──▶  Firestore (세계 상태: 국가·영토·시장·조약)
   (Next.js/Vite,        ──쓰기(모든 변경)──▶  Cloud Functions (서버 권위 검증)
    Firebase Hosting)                              │
[Cloud Scheduler] ──정기 틱──▶ Function: worldTick ─┘ (경제 정산·전투 판정·이자)
Firebase Auth (Google 로그인 / 익명→승격)
Cloud Messaging (피침·조약·틱 결과 푸시 알림)
```

- **모든 세계 상태 변경은 Cloud Function을 거친다.** 클라이언트는 세계 상태를
  직접 쓰지 못함(Firestore 보안 규칙: 세계 컬렉션 write 금지, 읽기만). → 2DStock의
  클라이언트 권위 문제를 원천 차단.
- **worldTick**: Cloud Scheduler가 N분마다 트리거. 활성 국가들의 생산·세수·이자·
  전투·안정도를 배치 정산. 큰 수는 전부 `exactAmount`.
- **실시간성**: Firestore onSnapshot 구독으로 지도·시장·전황 라이브 갱신. 고빈도
  일시 데이터(부대 이동 등)가 필요하면 Realtime DB 병용.
- **큰 수 처리**: `src/lib/number/exactAmount.ts` — 클라이언트(표시)와
  Function(연산)이 **동일 모듈 공유**. Firestore는 BigInt를 못 담으므로 정수
  문자열로 저장하는 이 설계가 정확히 들어맞는다. (이미 이식·테스트 완료.)
- **부정행위 방지**: 서버 권위 + 액션 rate limit + 서버 측 불변식 검증(음수 국고
  금지, 자원 보존 등).

## 5. MVP 범위 (기능 스프롤 재발 방지)

2DStock의 교훈: **한 번에 다 만들지 않는다.** 수직 슬라이스부터.

**MVP (재미의 최소 루프 1개):**
1. Google 로그인 → 국가 건국(맵에 깃발) → 수도 1칸.
2. 단순 경제: 자원 1~2종 + 국고. worldTick으로 생산·세수 정산.
3. 다른 유저와 **무역 1건** 체결.
4. **불가침 조약 1건** 체결/파기(평판 변동).
5. **선전포고 → 다틱 전투 → 영토 1칸 점령**의 완결.
6. 피침 시 푸시 알림 + 오프라인 자동 방어.

이 루프가 "재밌다"가 확인되면 통화/인플레·정부형태·연합·에포크·첩보를 순차 확장.

  Run/일반 GCP?

- 세계 모델: 완전 지속 vs 에포크(시즌) 소프트 리셋 — 본 제안은 **에포크 권장**.
- 맵: 헥스 그리드 vs 지역/노드 그래프 vs 자유 좌표?
